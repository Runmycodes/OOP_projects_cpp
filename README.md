# OOP_projects_cpp
Cpp object oriented projects that jump into in-depth topics, virtuality, inheritance, polymorphism, and so on.  

# Vehicle Renting System
Key Features include a pure Virtual class, derived classes that inherit from it for displaying and allocating private data. A menu system, and the usage of vectors that hold pointers to memory addresses.
Learned the importance of the 'new' keyword, alongside the restrictions of object creation withing a switch. Realized importance of override, and why vectors also need to be iterated through to delete each block of memory in the heap!

# Warehouse
Key Features include Composition of class utilizing Vectors. Adding various products of user's choice to two warehouses, and being able to calculate total net worth across all warehouses.
Learned an especially important concept of copy constructor. Understood how a destructor works and how constructors don't initiate again in a copy.
